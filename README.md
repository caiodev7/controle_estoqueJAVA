# Controle de Estoque em Java

## Sobre o projeto

Este projeto foi desenvolvido em Java puro com o objetivo de praticar Programação Orientada a Objetos (POO), manipulação de listas (`ArrayList`) e operações CRUD em memória.

O sistema funciona através do console e simula um pequeno controle de estoque de produtos.

---

## Funcionalidades

* Cadastro de produtos
* Listagem de produtos
* Busca de produto por nome
* Atualização de preço
* Adição de estoque
* Remoção de estoque
* Remoção de produtos
* Verificação de produtos com estoque baixo
* Exibição do produto mais caro

---

## Tecnologias utilizadas

* Java

* Programação Orientada a Objetos (POO)
